# KaizenCommerce Skill Composition — Full Combination Catalog

Reference file for the kaizen-commerce-expert skill. SKILL.md keeps the most common skill
combinations inline for fast routing. The full catalog of documented combinations lives here.
Load this file when (a) a task clearly spans two skill domains and the SKILL.md shortlist doesn't
cover the pairing, or (b) you're orchestrating a multi-skill engagement and need to plan the full
handoff sequence.

## Skill Composition — Full Catalog

Some tasks need two skills working together. When a task spans multiple skills, read all relevant files before generating output. The primary skill drives the output structure; supporting skills provide domain knowledge.

Common combinations:
- **dataprep + validate:** Preparing migration-ready data, then triaging API job logs, Dry Run results, or live import evidence
- **architect + flow:** Designing AnyDB schema alongside Shopify Flow automations
- **diagnose + retail-expert:** Blueprint report that needs deep POS or inventory knowledge
- **qualify + retail-expert:** Discovery call prep that needs domain-specific question depth
- **migrate + dataprep:** Runbook planning alongside actual file-level data work
- **anydb-dataload + anydb-audit:** Loading seed data, then verifying the build
- **scope + propose:** Change order that references the original proposal for delta calculation
- **hardware + onboard:** Hardware procurement planning during project kickoff
- **training + migrate:** Staff training plan designed around the migration cutover timeline
- **training + retail-expert:** Training curriculum that needs deep POS feature knowledge per role
- **hardware + retail-expert:** Hardware spec that needs device compatibility and regional availability detail
- **research + qualify:** Pre-call merchant research feeding into targeted discovery questions
- **memory + any skill:** Read client context before generating, write updates after
- **check + any deliverable:** Validate proposals, specs, runbooks before client delivery
- **generate + dataprep:** Transform cleaned data into API payload samples, Matrixify files when selected, or test fixtures
- **generate + architect:** Transform AnyDB spec into build configuration
- **render + propose/diagnose/report:** Style any deliverable as branded PDF or Google Doc
- **content-calendar + publish:** Calendar generates topics, publish creates the formatted content
- **finance + pipeline:** Financial review informed by pipeline data and deal history
- **firm-economics + propose:** Pricing a new engagement against profit per person and work-type classification
- **firm-economics + pipeline:** Capacity, utilization, and bench read against the live deal pipeline
- **productize + diagnose/architect:** Turning a recurring diagnosis or architecture pattern into a packaged accelerator
- **partner-ecosystem + research:** Sourcing co-sell overlap accounts during merchant or partner research
- **scope (SOW governance) + propose:** Writing exclusions, assumptions, data caps, and approval gates into the SOW at proposal time
- **proactive + all skills:** Every handoff block includes context-aware next-step suggestions
- **followup + check:** Validate follow-up email before sending — mandatory for Modes 3–4 (post-proposal, post-kickoff), recommended for all modes
- **followup + memory:** Read client context before writing, log the communication event after sending
- **followup + retail-expert-v2:** When the follow-up needs deep POS, inventory, or workflow knowledge to explain a recommendation accurately
