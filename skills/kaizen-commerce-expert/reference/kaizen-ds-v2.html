Brand Specification v1.0 · 2024
01 · Color

Four-color palette. No exceptions.

Every color serves a structural role. Adding new colors is a breaking change. When in doubt, use Black.

Black
#0e0e0e
Primary background. Default surface. 60–70% visual weight.
Mid Black
#181818
Secondary cells. Contrast against primary black only.
Deep Navy
#0D1B2A
Process, trust, featured context. Blueprint & Gold tier.
Red
#a8201a
Problem framing, primary CTA, urgency. Use sparingly.
White
#F5F7F9
Maximum contrast. CTA buttons on dark. Rare emphasis only.
Ice Blue
#aaccdb
Text accent on Navy only. Never used as a background.
Black dominates. 60–70% of every layout. It is the resting state of the brand.
Red means action or pain. Problem sections and primary CTAs. One red zone per page section maximum.
Navy means process and trust. Reserved for Blueprint steps, featured tiers, and credentialing moments.
White is a signal, not a field. Use only for maximum-contrast buttons and isolated highlight moments — never as a section background.
Ice Blue is Navy's accent. Text only, on Navy backgrounds. Never use as fill, never use on black.

03 · Grid & Spacing

Bento grid. Hairline gaps.

The layout system is a single flat grid. Hierarchy comes from background fills, not elevation. The 1px gap between cells IS the border — do not add additional CSS borders to cells.

Base Unit
8px — all spacing is a multiple of this
Grid Gap
1px — the gap between bento cells; sets the grid line color via wrapper background
Page Margin
40px — outer margin of all bento wrappers
Cell Padding
56px top/bottom · 60px left/right — default for full cells
Compact Pad
44px — stat cells and secondary cells
→
Bento wrappers have borders, cells do not. Set background: rgba(245,247,249,0.07) on the wrapper and gap: 1px. The wrapper color bleeds through the gap to form grid lines.
→
No border-radius anywhere. 0px on all elements — buttons, inputs, cells, images. The sharp grid is the brand.
→
No shadows or Z-axis depth. Hierarchy is tonal: use background fill contrast, not elevation. Active states are high-contrast reversals.
→
Adjacent bentos share a border. Remove duplicate border with border-top: none on all sections after the first. The page reads as one continuous grid.
04 · Components

Flat primitives only.

No cards, no modals, no floating layers. Every component is either a cell-fill, a text style, or a line.

✓ Do
Use flat background fills to define cell context. Let the 1px gap be the border. Use Garamond for numbers and editorial copy. Use ghost inputs with bottom-border only. Keep all interactive elements as full-width rectangular blocks.
✗ Don't
Add border-radius to anything. Use box-shadows. Nest cards inside cells. Use purple, orange, teal, or any color outside the system. Use Inter, Space Grotesk, or Geist. Add decorative dividers, horizontal rules styled as accents, or gradient overlays.
05 · Color Semantics

Color assigns meaning, not mood.

The same color means the same thing everywhere — across the website, decks, proposals, and print.

R
Red = Problem & Action. Pain points, obstacles, urgency, and primary CTAs. If you're using red, something is wrong (pain framing) or something must be done right now (CTA).
N
Navy = Process & Trust. The Blueprint diagnostic, methodology, featured tier. Moments where you're building credibility or walking someone through a structured approach.
B
Black = Default & Authority. Everything that isn't red or navy. The brand rests here. Black cells are neutral — they don't signal anything beyond "this is information."
W
White = Maximum Contrast Only. The primary CTA button on dark backgrounds. Occasionally a single emphasis cell in a hero bento. Never a section background. White is used to create a single focal point per view.
